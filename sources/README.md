# Source Archive

This directory is the evidentiary archive for PCA-Data.

The public site is generated from normalized data under `/data`, but every material claim should ultimately resolve to evidence preserved or registered here.

## Structure

- `raw/` — original evidence files preserved as close as practical to the publicly available source: PDFs, exported webpages, letters, reports, minutes, email archives, and other primary documents.
- `extracts/` — normalized human-readable or machine-readable extracts derived from raw sources, such as signer lists, membership tables, committee rosters, and page/message indexes.
- `manifests/` — provenance records describing source title, publisher, original URL, archive URL, retrieval date, local raw-file path, checksum when available, and any redistribution limitations.

## Evidentiary rules

1. Primary sources are preferred over commentary.
2. A raw file should not be edited to make a point. Corrections, annotations, OCR fixes, and normalized tables belong in `extracts/`.
3. If a source cannot appropriately be redistributed, store a provenance manifest and external/archive links rather than copying the work into the repository.
4. Each normalized affiliation or event should eventually cite one or more source IDs that can be traced to this archive.
5. Same-name matches are never enough to merge identities without corroborating information.
6. Network membership, event participation, institutional employment, public-letter signatures, and ideological interpretation remain separate evidence categories.
