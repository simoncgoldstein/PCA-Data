# Normalized Source Extracts

Derived research tables live here. They must preserve the evidentiary distinction present in the raw sources and point back to a raw file or provenance manifest.

Examples:

- National Partnership explicit-member roster by year
- National Partnership committee-placement table
- Protest and minority-report signer lists
- Garris-letter signer lists
- Prayer & Lament verified signer list
- AMR historical/current leadership rosters

Every extract should document how names were normalized and any unresolved identity collisions.
