# Source Provenance Manifests

Use one manifest per source family or document set. Each record should include, where available:

- source ID used by `/data/sources.json`
- title
- creator / publisher
- document date
- original URL
- archive/mirror URL
- retrieval date
- local raw-file path
- SHA-256 checksum
- source type (primary, official denominational record, first-party organizational record, secondary)
- redistribution note
- relevant pages/messages/sections
- normalization notes

A source can remain externally hosted if redistribution is inappropriate, but its manifest should still preserve provenance and the exact evidence location used by the project.
