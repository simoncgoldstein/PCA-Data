# Raw Evidence

Preserve original source material here without substantive editing.

Use subdirectories by source family. Where redistribution is inappropriate or technically impractical, preserve a provenance record under `../manifests/` with the original URL, archived URL when available, retrieval date, and description of the evidence used.

Files in this directory are evidence, not analysis. Derived signer lists, membership tables, OCR corrections, page indexes, and annotations belong under `../extracts/`.
