# Alliance for Mission & Renewal media archive

AMR is an active PCA network and should be harvested as a continuing source rather than treated only through its 2023 founding statement.

## Primary channels

- Main site: https://a4mr.org/
- Blog/archive: https://a4mr.org/blog/
- Substack: https://a4mr.substack.com/
- Substack about page: https://a4mr.substack.com/about
- YouTube: https://www.youtube.com/@AllianceforMissionandRenewal

## What to extract from every item

For articles, podcasts, videos, panels, and roundtables preserve:

- title
- publication date
- content type
- author(s)
- host/moderator
- guest/panelist names
- current roles as stated in the source
- event or GA context
- topics/issues discussed
- exact primary URL
- transcript/caption source when available
- archival/local copy status
- person-level claims or formal recommendations only when stated directly

## Transcript policy

YouTube/Substack audio/video participation is evidence of participation in that specific conversation, not automatic endorsement of every view expressed by another participant.

Where official captions/transcripts are retrievable, preserve them or a normalized transcript extract. If the channel blocks reliable transcript access, request user-supplied transcript exports rather than relying on automated summaries.
